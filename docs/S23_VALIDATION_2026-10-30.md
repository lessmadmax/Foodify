Gemma와 OpenAI 모두 밥으로 인식. Gemma 분석 직후 앱 전체 PSS 표시값은 3281MB. 최고 메모리 사용량이나 모델 단독 사용량으로 해석하지 않는다.
OpenAI 시간은 HTTP 요청부터 전체 응답 수신·파싱까지로 네트워크 포함. 실제 앱 업로드·작업 대기·DB 후보 선택·영양 계산·화면 폴링은 제외한다. 따라서 실제 사용자가 보는 전체 대기 시간과 구분한다.
음식명 비교에서 로컬은 초기화 포함 약 5.3배, 추론만 약 3.8배 오래 걸렸다. 한 장 1회 시험으로 일반 성능을 확정할 수 없다. 반복·다중 음식·기기 온도·네트워크 조건을 포함한 평가가 필요하다.
현 구현은 매 요청마다 모델 초기화·종료를 수행한다. 모델 유지·가속기 최적화는 이후 실험 항목이다.
