# 같은 음식 사진 30장 세 모델 비교 2026-11-02

기존 50종 평가 자료의 앞 30장을 실행 전에 고정하여 세 방식을 새로 실행했다. 각기 다른 30개 음식 분류에서 사진 1장씩이다. 사진·출처·원본 해시는 manifest.json에 보관한다.

|모델|정답 수|주 음식명 일치율|
|---|---:|---:|
|OpenAI gpt-4o-mini|16/30|53.33%|
|Gemma 4 E2B GPU|6/30|20.00%|
|Food-101-93M S23|28/30|93.33%|

한국어 번역·동등 표현은 인정하고 상위 음식명·재료명만 제시한 경우는 미일치로 처리한다. 된장국은 miso_soup의 번역으로 인정했다. 아보카도 소스는 과카몰리의 구체 메뉴 식별로, 참치·연어 등의 재료명만 나열한 것은 생선회 식별로 인정하지 않았다. 판정 별칭과 각 출력은 comparison.json에 공개한다. 추가 반찬의 오인식까지 포함한 검출 정확도와 구분한다.
Gemma의 형식 오류 2건은 정답 수 0으로, 분모 30에 포함하였다. 정답 이름은 어느 모델에도 입력하지 않았다. API에는 Food-101 후보를 전달하지 않았으며 기존 음식명·중량·재료·가정 프롬프트를 사용했다. Gemma는 음식명 JSON을 생성했다. Food-101은 학습한 101개 분류 중 첫 후보를 출력했다.
분류 모델은 Food-101 추가 학습 모델이며 다른 두 방식은 자유 생성이므로 과제·학습 데이터 조건이 다르다. 30장은 기존 자료의 재사용이며 독립된 최종 평가가 아니다. 분류당 1장·음식 구성·제작자 학습 데이터 중복 여부 미확인·언어별 동등 표현 판정의 한계를 함께 고려한다.
화면 잠금으로 중단된 로컬 실행은 제외하고, 잠금을 해제한 뒤 새 프로세스로 재실행한 30장 결과를 사용했다. 기기 화면 유지 임시 설정은 평가 종료 후 복원한다.
