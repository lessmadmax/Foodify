# 동일 음식 API·GPU 비교 (2026-11-02)

Food-101 validation의 같은 원본 사진 6장. OpenAiClient의 기존 음식명·중량·재료·가정 프롬프트 및 JSON 스키마를 재현하여 gpt-4o-mini Responses API 호출. 512px JPEG quality85, 촬영 근거 guided_photos/volumeValidated=false. 정답 라벨은 전달하지 않음.

API 전체 평균 4.914초. 첫 GPU 초기화 실행을 제외한 같은 5장의 API 평균 4.571초, GPU 평균 2.124초. GPU 첫 사진의 초기화 5.94초는 표의 추론 시간과 별도.

API는 음식명뿐 아니라 중량·재료·가정을 출력했고, 로컬은 음식명만 출력했다. API는 네트워크 포함 HTTP 요청부터 응답 파싱까지 측정. 앱 업로드·작업 대기·영양 DB 매칭·계산·폴링 제외. Android와 Python의 이미지 변환 경로가 달라 입력 JPEG 바이트까지 동일한 시험은 아니다. 각 사진 1회 측정이며 일반 성능을 보장하지 않는다.

API는 포크찹의 고기 종류와 당근 케이크 세부 이름에서 Gemma보다 나은 결과였다. 프라임 립은 양지머리로 오인식했고, 프로즌 요거트는 소프트 아이스크림으로 혼동했다. API가 추가한 반찬·재료는 별도 검증이 필요하며 실측 중량 자료가 없어 중량 정확도를 판단할 수 없다.

원시 출력·사용량: data/private/gpu-food-eval/food101/openai-results.json. 직접 API 호출 6건은 OpenAI 청구 사용량에 포함되며 앱 ai_usage/ai_budget에는 자동 반영되지 않는다.
