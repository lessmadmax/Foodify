# Food-101-93M 서비스 연결

촬영·갤러리 사진을 분석할 때 Android에서 Food-101-93M이 이미지별 주 음식 상위 3개 후보를 먼저 계산한다. 후보는 captureInfo.foodRecognition으로 업로드 대기 기록과 서버 식단 기록에 저장한다. 서버는 모델·버전·사진 번호·101개 허용 음식명·유한한 점수를 검증하고 기존 OpenAI 음식·중량 분석에 근거로 전달한다.

이 적용은 로컬 분류와 API의 결합이다. 여러 음식의 검출·중량 추정·분류 밖 음식 확인은 기존 API가 이어서 처리하고, 영양 계산은 공공 DB 기준을 유지한다. 분류 모델의 첫 후보를 한 끼 전체나 모든 음식에 강제 적용하지 않는다. 기기 분류 실패·미지원 환경은 안내 후 기존 사진 분석으로 이어간다. 기존 저장 기록은 재분석 전까지 과거 결과를 유지한다.
