# 영양정보 화면 변경 (2026-10-11)

## 결과 표시 간소화

- 결과 카드와 최근 식단 목록에 저장된 음식명을 표시. 분석 이름 또는 사용자 보정 이름을 사용하며, 빈 이름은 '음식명 확인 필요'로 표시. 음식명 표시는 인식 정확도 보장과 구별.
- 최근 식단 목록은 음식명을 쉼표로 연결하고 최대 두 줄까지 표시.
- AI 중량·예상 범위·가정·불확실성 설명의 숨김과 수동 보정 기능은 유지.
- 내부 추정 데이터는 계산을 위해 유지. 별도로 요청하는 개인화 피드백은 유지.
- 내부 DB ID 표시를 음식 변경/음식 선택으로 대체. 미연결 음식은 공공 영양 자료의 후보를 제시.
- 공공 자료의 음식명·자료원·기준량·버전은 계산 근거 보기를 펼쳐 확인 가능. AI 원문과 구별.
- 직접 보정 입력란은 접이식이며 AI 값으로 미리 채우지 않음. 수정 없이 저장할 때는 기존 내부 계산값 유지.

- 앱 테마: 초록색 상단 바·주요 버튼, 연한 초록 배경 및 표 항목 셀.
- 영양정보: 칼로리(kcal), 탄수화물(g), 단백질(g), 지방(g)의 4행 2열 표.
- 동일 표를 홈 합계·하루 참고 목표·식단 전체·음식별 결과에서 사용.
- 결과 화면: 상단 한 끼 전체 합계 → 분석 근거 및 상태 → 음식별 결과와 보정 입력.
- 각 영양소의 전체 합계는 모든 음식에 해당 값이 확보되었을 때 표시. 미상은 0과 구분하여 계산 대기로 표시.
- 편집 중에는 전체 합계를 계산 대기로 전환하고, 저장 응답으로 갱신.
- 분석 대기/진행 상태에서 전용 로딩 화면, 3초 간격 상태 갱신 유지.
- 서버 분석 중지 상태에는 중지 안내, 조회 실패에는 재확인 버튼 제공.
- 자동 분석 완료·미완료 응답을 받으면 결과/보정 화면으로 전환.

검증: nutrition_table_test.dart에서 4행 2열 구조, 미상/0 구분, 합계, 로딩→결과 전환, 표시 순서와 중지 안내를 확인한다. 기존 저장·목표 계산 테스트도 표 형식에 맞춰 유지한다.
