## 증거·업데이트 규칙

- 마지막 확인한 테스트: 서버 21개, Flutter 16개, Android 깊이 처리 6개 통과. 이번 저장 UI 수정에서는 Flutter 16개 및 정적 분석(지적 0건)을 재실행했다. 서버·Android 및 데이터 변환 Python 테스트 3개는 앞선 작업의 결과다.
- 마지막 확인한 기기: Galaxy S23 SM-S911N, Android 16, AR 서비스 설치됨. AR 실측은 마지막 확인 당시 잠금 화면으로 미검증.
- 마지막 확인한 실행: 최신 debug APK 설치 성공, 로컬 서버 UP, adb reverse 설정. 현재도 켜져 있는지는 실행 시 다시 확인한다.
- 실제 OpenAI 음식 분석 성공, MySQL/RDS 검증, AWS 배포, 정확도 목표 달성은 결과 증거 확보 후 체크한다.
- 새 작업은 고유 ID를 붙인다. 완료로 바꿀 때는 테스트명/실행 결과/산출물 경로와 확인 날짜를 적고 상단·영역별 건수를 함께 갱신한다.
