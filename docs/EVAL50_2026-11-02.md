평가 조건: 50개 서로 다른 음식 분류에서 각 1장. 모델에 정답 이름을 전달하지 않았다. S23 Adreno 740 GPU, Gemma 4 E2B, LiteRT-LM 0.16.1. 기존 API는 gpt-4o-mini-2024-07-18로 음식명·중량·재료·가정 구조를 생성했다. 로컬은 음식명만 생성했다. 둘 다 최대 512px JPEG 처리이나 변환 경로·재인코딩은 다르다. 원본 50개 전송 SHA256 일치 확인.
API는 네트워크 포함 요청~응답 수신·파싱 시간, Gemma는 기기 내 추론 시간이다. 업로드·작업 대기·DB 검색·영양 계산·화면 갱신은 제외한다. GPU 정상 재사용 45건 평균을 사용하며 형식 오류 2건의 지연과 초기화 3건은 해당 평균에서 제외한다. 오류는 정확도 분모 50에는 포함한다.
일부 사진은 앞선 6장 실험과 중복될 수 있으며, 제공 데이터의 서양 음식 비중·라벨 모호성·분류당 1장·요청 형식 차이·수동 단일 채점 등의 한계가 있다. 한국 음식 전체 성능 또는 실제 중량 정확도로 일반화할 수 없다. 동일 프롬프트 비교와 한식 반복 평가를 후속으로 수행한다.
기기 내 연속 시험용 debug 경로는 앱 내부 고정 디렉토리만 사용하며 일반 식단 분석은 기존 API를 유지한다. 추가 새 엔진 재검증 3장은 정량 분모에 포함하지 않았다.
