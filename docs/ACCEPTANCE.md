# Foodify 시연 및 평가 체크리스트

## 기본 시연

- [ ] 서로 다른 회원 2명을 만들고 각자의 기록만 조회한다.
- [ ] 하루 영양 목표를 입력하고 다시 로그인해 값이 유지되는지 확인한다.
- [ ] 한 끼를 서로 다른 각도에서 최대 3장 촬영한다.
- [ ] 업로드 중 네트워크를 끊고 앱을 재시작한 뒤 동일 기록으로 재전송한다.
- [ ] 음식명·중량·공공 DB 항목을 수정하고 영양 계산값을 확인한다.
- [ ] 완료 식단만 일간·주간 합계에 반영되는지 확인한다.
- [ ] 피드백을 요청하고 기록 수정 후 이전 피드백의 stale 여부를 확인한다.
- [ ] 사진·식단·계정을 삭제하고 다른 계정·폐기된 토큰의 접근을 확인한다.
- [ ] 서버를 분석 도중 재시작하고 작업 복구를 확인한다.
- [ ] 사진 보관소 장애를 복구한 후 삭제 대기 작업이 완료되는지 확인한다.

## 정확도 평가

음식 인식은 50끼 중 30끼 개발용·20끼 고정 평가용으로 나눈다. 제공량 실험은 음식 3종 × 제공량 10개 × 반복 2회로 진행한다. 같은 제공량의 반복 사진은 한 분할에 넣는다.

평가 열: sample_id, split, device, food_name, actual_grams, estimated_grams, corrected_grams, analysis_status, elapsed_ms, input_tokens, output_tokens.

자동 결과 확보율과 오차를 함께 보고한다. 실패 항목을 버리고 성공한 결과의 오차만 보고하지 않는다. 초기 채택 목표는 검증 자료 중량 상대오차 중앙값 25% 이하·자동 결과 확보율 80% 이상이다. 아직 측정 결과가 없다.
