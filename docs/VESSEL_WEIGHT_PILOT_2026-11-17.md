# 그릇 기본 깊이와 AR 정보의 중량 추정 예비 비교

## 목적

사용자가 승인한 11/13 기존 음식 사진과 AR 정보를 OpenAI API에 전송하여, 사진 단독 대비 AR 정보와 그릇 기본 깊이 제공이 도움이 되는지 확인하였다. 그릇은 AI가 내부 판별하고 사용자에게 선택·표시를 요구하지 않는 방향을 시험하였다. 앱 통합 구현은 하지 않았다.

## 방법

- 모델: gpt-4o-mini, Responses API, 조건당 독립 요청 3회, 총 9회. 자동 재시도 없음. 요청에 `store=false` 지정.
- 사진: 세션 `2a1b4f53-0c32-4dd8-9cdd-dfb7758a4eca/frame-01/analysis.jpg`, 640×480. 저울 숫자가 보이지 않는 마지막 촬영 원본을 사용했다. 한 제공량·한 사진을 반복한 것이며 독립 표본 9개가 아니다.
- 정답: 대화상 같은 105g을 유지한 것으로 간주. 마지막 사진의 재계량은 별도 확인하지 않았다. 정답은 점수 계산에만 사용하고 모든 요청에서 제외했다.
- A 사진만: 사진에서 음식·그릇 종류와 중량 추정. 추가 크기·AR·그릇 기본값 없음.
- B 사진+AR: A에 앱 표시 면적 184.8cm², 기준면 거리 42.4cm, 특징점 평균 높이 4.29cm(27개), 2프레임·기울기, 대표 원시 프레임의 장면 신뢰 깊이 비율 약 4.3%를 추가했다. 기준면 배경 혼입·높이 편향 가능성과 수치가 미검증임을 설명했다. 장면 통계는 음식 영역·결합 깊이 품질이 아님을 명시했다.
- C 사진+AR+그릇 기본 깊이: B에 밥그릇 5.8cm, 평면 접시 0.8cm, 국그릇 3.0cm, 깊은 접시 3.5cm를 제공하고 사진에서 종류를 고르게 했다. 개별 제품·제작 사례 기반 임시값이며 실제 그릇 실측이 아니라고 명시했다. 그릇 깊이와 음식 높이를 같게 쓰지 않도록 지시했다.
- 공통으로 근거가 부족하면 중량 null을 허용했다. 음식명·그릇 종류·중량·가정을 구조화해 받았다. 기존 499.5g 추정값과 밀도는 AI에 제공하지 않았다.
- 기존 산술 결과 499.5g은 과거 앱 표시값으로 비교했으며 이번에 다시 계산·측정한 것이 아니다. 최종 음식 마스크는 재현하지 않았고 면적·거리·높이는 앱의 반올림 표시값을 사용했다.

실행 스크립트: `scripts/compare_weight_vessel_pilot.py`. 비공개 근거: `data/private/ar/vessel-pilot-2026-11-17/`의 manifest, 9개 응답, summary. API 키는 저장하지 않았다.

그릇 종류는 9/9회 `flat_plate`였다. 한 사진에 대한 반복 일치이며 다양한 그릇 분류 정확도를 뜻하지 않는다. 평균 응답 시간은 A 약 5.41초, B 약 2.68초, C 약 2.61초다. 대기·준비·앱 통합 시간을 포함한 전체 서비스 시간이 아니다. 총 입력 토큰 131,553, 출력 토큰 904이며 과금액은 계산하지 않았다.

## 해석

이 구성에서는 AR 또는 그릇 깊이를 더해 중량 정확도가 향상됐다는 증거를 얻지 못했다. B와 C는 수치가 없어 중량 오차의 우열을 비교할 수 없으며 결과 확보율이 낮았다. 불확실한 AR 정보를 추가하면 항상 더 정확해진다는 가정은 지지되지 않았다.

A는 일반 제공량을 그대로 쓰지 말라는 지시에도 전형적인 간식 제공량을 근거로 들었다. C의 일부 응답은 그릇 내부 깊이 0.8cm를 접시 두께처럼 표현하거나, 음식 높이 4.29cm와 직접 비교했다. 따라서 기본값을 전달하고 그릇을 분류하는 것만으로 올바른 기하 계산이 보장되지 않았다.

B/C에는 거리·면적뿐 아니라 이미 의심스러운 높이와 품질 경고도 같이 추가되었다. 이번 결과만으로 정확한 거리·면적 자체의 효과와 잘못된 높이·경고의 효과를 분리할 수 없다. LLM이 그릇 테두리를 찾거나 등록 깊이로 기준면을 보정한 실험도 아니다. 중량 산출에 성공한 사례만으로 방법을 선정해서는 안 된다.

## 결론과 다음 계획

다음 검증은 같은 자료에서 의심 높이 4.29cm를 제외하고 거리·면적만 제공하는 조건을 분리하는 것이 우선이다. 깊이 정의는 내부 바닥에서 테두리까지의 수직 거리로 고정하고, 음식 두께·바닥 두께와 분리된 필드로 다룬다. 그릇을 자동 분류하는 경로와, 그 분류를 이용해 실제로 기준면을 보정하는 경로를 구분한다. 추가 호출은 이번 승인 9회에 포함되지 않으며 새 실행 범위를 정한 뒤 진행한다.

그릇 판별을 화면에 노출하지 않는 사용자 요구는 유지하되, 내부 기록에 종류·기본 깊이·불명 상태를 남기고 잘못된 수치의 전달 및 중량 미확보 처리 기준을 설계해야 한다. 현재 앱의 중량 방식은 변경하지 않았다.

## 한계

단일 음식·제공량·사진, 재계량 미확인, 정확한 최종 영역 부재, 미검증 AR 수치와 일반화할 수 없는 그릇 기본값, 조건별 3회의 작은 반복이다. 모델 생성 변동과 이번 프롬프트의 판단 보류 허용이 결과에 영향을 준다. 이 결과를 전체 음식 정확도나 독립 평가 성능으로 보고하지 않는다.
