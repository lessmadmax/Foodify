자료: https://huggingface.co/datasets/ethz/food101 의 validation 사진 6장. 원본 행 번호·파일은 data/private/gpu-food-eval/food101/manifest.json, 실제 화면 출력은 s23-results.json에 저장했다. 정답 라벨은 추론 프롬프트에 전달하지 않았다.

모델 재사용 5회 추론 평균 2.124초, 최소 1.88초, 최대 2.58초. 첫 실행은 초기화 포함 12.57초(5.94+6.63). 사진 선택·파일 변환·화면 조작 시간은 포함하지 않는다.

세부 분류 일치는 2/6이며, 일반 인식 정확도 추정치로 해석하기에 표본이 작다. 상위 분류와 세부 분류를 구분하여 실패 사례로 기록한다. 추가로 나열된 반찬·소스는 Food-101 주 음식 라벨로 정오를 검증하지 않았으므로 정답 수에 포함하지 않았다.

결론: 서로 다른 이미지에서도 GPU 모델 재사용 시 약 2초대 음식명 추론을 관찰했다. 고기 종류와 유사 디저트, 케이크의 재료 식별은 보완할 영역이다. 중량·영양 계산 정확도는 이번 시험 대상과 구분한다. OpenAI와 같은 사진 6장으로 동시 비교한 결과는 아직 없다.
