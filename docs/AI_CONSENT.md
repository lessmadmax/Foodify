# 최초 AI 전송 안내·동의 (2026-10-08)

## 흐름

첫 업로드/재전송/재분석/피드백 요청 → 서버의 회원별 동의 조회 → 미동의·철회·버전 변경이면 안내 화면 → 명시적 동의 저장 → 요청 실행.
동의가 유효하면 재조회만 수행하고 안내 화면을 생략한다. 나중에/뒤로 가기는 AI 요청을 실행하지 않는다.
설정 > AI 전송 안내 및 동의에서 현재 안내, 마지막 동의 시각·버전과 철회 시각을 확인하고 철회할 수 있다.

## 서버

- GET /api/v1/me/ai-consent: 현재 버전·안내·회원 동의 상태
- PUT /api/v1/me/ai-consent: {"version":"2026-10-08-v1","accepted":true}
- DELETE /api/v1/me/ai-consent: 동의 철회
- V4 마이그레이션: members의 동의 버전·동의/철회 UTC epoch 시각, ai_consent_events 이력(계정 삭제 시 cascade).
- 이전 촬영 체크박스 값으로 신규 동의를 자동 등록하지 않는다. 기존 회원도 첫 이용 시 안내.
- 업로드의 consent=true 값을 권한 근거로 사용하지 않고 서버 저장 상태를 확인한다.
- 업로드/재분석/피드백 및 분석 작업 실행 전 상태 검증. 미동의 작업은 AI_CONSENT_REQUIRED 사유와 INCOMPLETE로 남고, 재동의 후 사용자가 재분석을 요청한다.
- 철회는 이미 승인·전송이 시작된 외부 요청을 회수하지 않는다. 매 단계 전 검증하며 기존 기록은 보존한다.
- AiConsent.VERSION 변경 시 재동의 필요. 안내 변경과 버전 변경을 함께 배포하며 이전 안내 문서는 Git 이력으로 보존한다.

## 공개 운영 전 확인

현재 안내는 시험 운영용이다. 실제 계정 계약의 수신 법인·연락처, 국외 처리 국가, 사업자 연락처, 법적 처리 근거와 민감정보 처리 여부 등을 확정하여 공개용 개인정보 처리방침 및 필요 동의서에 반영한다. 이 UI 구현 자체가 법적 요건 충족의 확인은 아니다.
OpenAI Docs의 보관 지침을 반영했다. 기존 Responses store:false 유지. 악용 모니터링의 기본 최대 30일 보관 및 법령·안전상 예외와 앱 사진 보관 기간을 구분한다.

서버: 계정별 격리, 잘못된 버전, 중복 동의 멱등성, 철회/재동의, 철회 후 업로드·재분석·피드백·대기 작업의 외부 호출 차단.
앱: 최초 안내, 취소, 재이용 시 생략, 설정 철회, 저장 실패 시 미동의 유지.
